# Indonesian Coffee Shop & F&B Consumer Trends Dataset

An automated synthetic dataset and interactive business intelligence web dashboard tracking coffee shop transactions, popular beverage categories, digital payment preferences, and customer satisfaction ratings across major cities in Indonesia.

## Dataset Features
*   **Scope:** Coffee shop transactions across major urban hubs (Jakarta, Bandung, Surabaya, Yogyakarta, Bali, Medan).
*   **Attributes:** Transaction ID, Transaction Date, City, Coffee Shop Brand/Outlet, Menu Category (Espresso Based, Manual Brew, Non-Coffee, Pastry/Food), Item Name, Price, Quantity, Payment Method (QRIS, E-Wallet, Credit Card, Cash), and Customer Rating.

## App Features
*   **Executive Metrics:** Real-time summary of Total Revenue, Total Transactions, Average Ticket Size (ATS), and Average Customer Satisfaction.
*   **Sales Analytics:** Revenue breakdown by menu categories, top-selling items, and payment method share using interactive Plotly charts.
*   **Interactive Filters:** Filter data dynamically by city, payment method, and menu category.
*   **Raw Data Explorer:** Search, filter, and download raw tabular data directly from the browser.
